# 【迭代N】重复周期应该必填，终止时间勾选了也应该必填。

## 现象
【测试环境】agent-workspace/schedule

【测试分支】develop

【测试账号】

## 根因
packages/<内部标识>-ai/lui/pages/schedule/schedule-editor.vue 中「重复周期」表单项（模板中 `<a-form-model-item :label="$t('languages.aiPlatform.interval')">`）没有绑定 prop、rules 中也没有对应规则，空重复周期可提交；「终止时间」只是普通 div（class="schedule-editor__end-row"），endAt 未进入表单校验，勾选后不填时间也能提交。

## 说明
给重复周期表单项绑定 prop="repeat" 并加上 required 星号与校验规则（校验 value 与其 scheduleType 是否存在），把终止时间块包进 `<a-form-model-item prop="endAt">` 并在 rules 中加条件校验（form.hasEndAt 为 true 时 endAt 必填）；这样点击确定时 form.validate 会拦截并给出「请选择」提示，同时监听 hasEndAt 变化清除残留校验提示。仅影响该弹窗的校验与提示行为，提交数据结构（submit 事件负载、endAt 是否传递）保持不变。
